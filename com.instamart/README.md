# Project Name

A Java-based project developed using Maven and the Spring Framework to understand Spring fundamentals and enterprise application development.

## Overview

This project focuses on learning and implementing fundamental concepts of the Spring Framework.

The initial implementation includes Maven project configuration, XML-based Spring configuration, and bean creation.

## Objectives

- Understand Maven project structure and dependency management.
- Understand the fundamentals of the Spring Framework.
- Learn Inversion of Control (IoC).
- Understand Spring Bean configuration using XML.
- Learn how the Spring IoC container manages objects.

## Technologies Used

| Technology | Purpose |
|---|---|
| Java | Programming language |
| Maven | Build and dependency management |
| Spring Framework | Application framework |
| XML | Spring bean configuration |
| Eclipse IDE | Development environment |
